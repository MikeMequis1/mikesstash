# 🛠️ Desenvolvimento do site

Esta página reúne algumas informações sobre como o *Mike's Stash* foi construído, além dos recursos e projetos utilizados em seu desenvolvimento.

## 🌱 Em constante desenvolvimento

O site não nasceu como um projeto com uma especificação completa e um planejamento detalhado. Ele foi crescendo aos poucos, conforme novas ideias apareciam.

Algumas funcionalidades começaram como pequenos experimentos e acabaram se tornando partes essenciais do site. Outras ainda estão na lista de coisas que quero testar, melhorar ou simplesmente descobrir se funcionam.

### 🟢 Finalizado

- Todas as histórias e desenhos publicados até julho de 2026;
- Descrição do projeto *Asher*;
- Seção de comentários;
- Alternância dinâmica de temas e idioma;
- Páginas principais traduzidas para o inglês;
- Exibição de *cards* modernos inspirados no *Material Design*;
- Temas Claro e Escuro;
- Temas personalizados **Nyxa** e **Lunara**;
- Mini-bio & páginas relacionadas;
- Visualizador de imagens para desenhos;
- Modo **Portfólio**;
  - Botão e alternância de modo;
  - Páginas envolvidas;
- Moedas sociais interativas (links de perfil em 3D);
- Documentação completa do **Asher**;

### 🟡 Em desenvolvimento

- Páginas do **Refúgio da Web**;
- Tradução das histórias de desenho para o inglês;
- Página sobre os problemas envolvendo imagens geradas por IA.

Esta lista também faz parte do próprio desenvolvimento do site e pode mudar conforme novas ideias aparecem.

## 🔧 Tecnologias

O site utiliza principalmente:

- [Obsidian](https://obsidian.md/) para criação e organização do conteúdo;
- [Digital Garden](https://github.com/oleeskild/digitalgarden) para publicação do conteúdo;
- [GitHub](https://github.com/) para versionamento e armazenamento do projeto;
- [Vercel](https://vercel.com/) para hospedagem;
- Eleventy e outras ferramentas utilizadas pelo template do Digital Garden;
- HTML, CSS e JavaScript para as personalizações e funcionalidades próprias do site.

Grande parte da interface foi modificada ou construída para que o site pudesse deixar de parecer apenas uma instalação padrão do Digital Garden.

# 🛠️ Site Development

This page contains some information about how *Mike's Stash* was built, along with the tools, features, and projects involved in its development.

## 🌱 Always evolving

The website didn't start as a project with a complete specification and a carefully detailed plan. It grew little by little, as new ideas came along.

Some features started as small experiments and eventually became important parts of the site. Others are still on the list of things I want to test, improve, or simply find out whether they work.

### 🟢 Completed

- All stories and drawings published up to July 2026;
- *Asher* project description;
- Comment section;
- Dynamic theme and language switching;
- Main pages translated into English;
- Modern *card* layouts inspired by *Material Design*;
- Light and Dark themes;
- Custom **Nyxa** and **Lunara** themes;
- Mini-bio & related pages.
- Image viewer for drawings;
- **Portfolio** mode;
  - Mode switch and toggle;
  - Related pages;
- Interactive social coins (3D profile links);
- Complete **Asher** documentation;

### 🟡 In development

- **Web Haven** pages;
- English translations for drawing stories;
- A page about the issues surrounding AI-generated images.

This list is also part of the site's development and may change as new ideas come along.

## 🔧 Technologies

The site mainly uses:

- [Obsidian](https://obsidian.md/) for creating and organizing content;
- [Digital Garden](https://github.com/oleeskild/digitalgarden) for publishing the content;
- [GitHub](https://github.com/) for version control and project storage;
- [Vercel](https://vercel.com/) for hosting;
- Eleventy and other tools provided by the Digital Garden template;
- HTML, CSS, and JavaScript for the site's customizations and features.

A large part of the interface has been modified or built specifically so the site could become more than just a standard Digital Garden installation.
