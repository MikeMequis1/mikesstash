# 🐱 Asher

:::lang pt

**Asher** é uma plataforma de modding baseada em launcher para [_Dust: An Elysian Tail_](https://store.steampowered.com/app/236090/Dust_An_Elysian_Tail/), com suporte a **patching de código em runtime** e **substituição de conteúdo** de forma segura, modular e reversível.

[Link de Repositório](https://github.com/MikeMequis1/Asher)

*Última atualização: 23 de setembro de 2026*

:::

:::lang en

**Asher** is a launcher-based modding platform for [_Dust: An Elysian Tail_](https://store.steampowered.com/app/236090/Dust_An_Elysian_Tail/), designed to support **runtime code patching** and **content replacement** in a safe, modular, and reversible way.

[Repository Link](https://github.com/MikeMequis1/Asher)

*Last Updated: September 23, 2026*
